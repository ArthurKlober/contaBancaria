# 🏦 Conta Bancária - C#

Projeto desenvolvido em **C#** com o objetivo de praticar os conceitos fundamentais de **Programação Orientada a Objetos (POO)**, trabalhando com criação de classes, objetos, propriedades, métodos e relacionamento entre classes.

## 📌 Desafio 01

Criar uma classe que representa uma conta bancária contendo as seguintes informações:

- Número indicador da conta;
- Titular;
- Saldo;
- Senha.

Após a criação da classe, foi realizado:

- Instanciação de um objeto do tipo `Conta`;
- Adição dos dados da conta;
- Exibição das informações do titular e saldo no console utilizando **interpolação de strings**;
- Desenvolvimento de um método responsável por exibir as informações da conta.

---

## 📌 Desafio 02

Reestruturação da classe `Conta` utilizando **Properties** para melhorar o encapsulamento dos atributos.

A modelagem da conta foi aprimorada adicionando:

- Classe `Titular` para representar o proprietário da conta;
- Agência;
- Número da conta;
- Saldo;
- Limite.

Também foi implementado um método responsável por retornar as informações detalhadas da conta.

Neste desafio foi realizado:

- Instanciação de um objeto `Conta`;
- Instanciação de um objeto `Titular`;
- Associação do titular à conta;
- Exibição das informações do titular através da classe `Conta`.
